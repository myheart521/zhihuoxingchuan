# 公开版本整理说明

- 使用工作副本导出源代码，没有复制原 Git 历史。
- 原数据库 dump、运行日志、用户上传、压缩包、IDE 配置、测试数据与原部署配置不发布。
- 后端包名、Maven 模块名及配置前缀已移除原个人和机构标识。
- 原私有主机、真实邮箱、手机号、长编号、模型密钥与对象存储链接已清理或改为本机/无效示例地址。
- 前端直接供应商请求改为默认关闭的后端适配器接口约定；原 RSA 私钥与记住密码逻辑已移除。
- 位图改用无个人信息的占位图。截图效果可能与原比赛展示版本不同。
- 仅保留建表语句，不包含初始管理员或历史业务数据。

这一整理版用于代码学习和后续开发。维护者应在自己的隔离环境中补齐初始数据、服务配置与业务验证。
