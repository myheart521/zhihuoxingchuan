# 智火星传界面图集

本页共 32 张图片，按功能分组。点击图片可以查看原尺寸。图片来自本地保存的项目截图，展示当时的界面；需要哪些服务、如何运行，以[配置说明](CONFIGURATION.md)为准。

账号头像、姓名、联系方式、服务凭据及历史业务记录按所在区域遮盖。灰色区域是隐私遮盖，不是应用本来的空白页；没有用虚构数据填回原记录。重复画面、证件与团队合照不列入图集。

这里只提供独立截图和技术图，不提供整页幻灯片或 PPT、PPTX、Word 原件。图中的第三方插图、人物形象和展厅内容仍适用各自的授权范围。
