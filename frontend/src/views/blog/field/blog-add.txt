# 博客新增功能所需后端接口

## 1. 博客相关接口

### 1.1 创建博客
- **接口路径**: `/api/blog/create`
- **请求方式**: POST
- **请求参数**:
  ```json
  {
    "title": "博客标题",
    "content": "博客内容（HTML格式）",
    "categoryId": 1,
    "tagIds": [1, 2, 3],
    "visibility": 0,
    "status": 1,
    "frontCover": "封面图片URL"
  }
  ```
- **参数说明**:
  - title: 博客标题，字符串，必填
  - content: 博客内容，HTML格式，必填
  - categoryId: 分类ID，整数，必填
  - tagIds: 标签ID数组，可选
  - visibility: 可见性，整数，0-公开，1-仅自己可见，2-粉丝可见，默认0
  - status: 状态，整数，0-草稿，1-待审核，默认0
  - frontCover: 封面图片URL，字符串，可选
- **返回结果**:
  ```json
  {
    "code": 200,
    "message": "创建成功",
    "data": {
      "id": 1,
      "title": "博客标题",
      "status": 0
    }
  }
  ```

### 1.2 保存草稿
- **接口路径**: `/api/blog/save-draft`
- **请求方式**: POST
- **请求参数**: 同创建博客接口
- **返回结果**: 同创建博客接口

### 1.3 获取草稿
- **接口路径**: `/api/blog/draft/{id}`
- **请求方式**: GET
- **请求参数**: 路径参数id
- **返回结果**:
  ```json
  {
    "code": 200,
    "message": "获取成功",
    "data": {
      "id": 1,
      "title": "博客标题",
      "content": "博客内容",
      "categoryId": 1,
      "tagIds": [1, 2, 3],
      "visibility": 0,
      "status": 0,
      "frontCover": "封面图片URL"
    }
  }
  ```

## 3. 文件上传接口

### 3.1 上传图片
- **接口路径**: `/api/upload/image`
- **请求方式**: POST
- **请求参数**: FormData格式，包含图片文件
- **返回结果**:
  ```json
  {
    "code": 200,
    "message": "上传成功",
    "data": {
      "url": "图片访问URL",
      "name": "图片名称"
    }
  }
  ```

### 3.2 上传封面图片
- **接口路径**: `/api/upload/cover`
- **请求方式**: POST
- **请求参数**: FormData格式，包含图片文件
- **返回结果**: 同上传图片接口

## 4. 数据库表关系

博客新增功能涉及以下数据库表：
1. `blog_post` - 存储博客基本信息
2. `blog_category` - 存储分类信息
3. `blog_tag` - 存储标签信息
4. `blog_post_tag` - 博客与标签的多对多关联表

创建博客时，需要同时处理：
1. 在 `blog_post` 表中插入博客记录
2. 在 `blog_post_tag` 表中插入博客与标签的关联记录

## 5. 注意事项
1. 富文本编辑器上传图片时，需要将图片存储到服务器或云存储，并返回可访问的URL
2. 博客内容需要进行XSS过滤，防止恶意代码注入
3. 用户提交审核的博客需要经过管理员审核后才能发布
4. 草稿状态的博客只有作者自己可见
5. 封面图片建议进行压缩和裁剪，以提高加载速度
6. 需要进行权限验证，确保用户只能操作自己的博客
